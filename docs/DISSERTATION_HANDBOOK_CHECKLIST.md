# COMP7039 final-report checklist

Source reviewed: `COMP7039 PG Computing Project Module Handbook S2 2025-6`.
Always check Moodle for the current deadline and summative marking rubric.

## Submission and length

- [ ] Submit one final-report file containing repository links.
- [ ] Include the compulsory Moodle cover sheet and electronic signature.
- [ ] Keep the assessed main body at or below 10,000 words (no more than 10%
      excess; words beyond that are not marked).
- [ ] Keep the abstract at or below 250 words.
- [ ] Exclude cover/title pages, contents, abstract, bibliography and appendices
      from the reported main-body count, following the handbook definition.
- [ ] Submit through Moodle/Turnitin by the deadline shown on Moodle.

## Required report evidence

- [ ] Number sections and subsections for cross-reference.
- [ ] Include a glossary of abbreviations.
- [ ] State background, aim, measurable objectives and product overview.
- [ ] Critically compare existing approaches in a themed literature review.
- [ ] Explain research and software-development methodology.
- [ ] Justify hardware, software, models, datasets and implementation tools.
- [ ] Explain version control and link the complete source repository.
- [ ] Document results, testing, constraints, limitations and originality.
- [ ] Include project activities, schedule, data management and deliverables.
- [ ] Analyse project/product risks, mitigations and changes to the plan.
- [ ] Address legal, social, ethical, environmental, sustainability and
      professional issues with relevant professional codes.
- [ ] Critically appraise the process and reflect on feedback received.
- [ ] Conclude against the objectives and identify defensible future work.
- [ ] Use IEEE or Harvard citations consistently.

## Presentation requirements

- [ ] Use 12-point Arial (the LaTeX draft uses compatible Liberation Sans until
      Arial is installed).
- [ ] Use 1.5 line spacing.
- [ ] Use at least 30 mm on the binding side and 20 mm on other sides.
- [ ] Centre page numbers in the bottom margin.
- [ ] Keep figures understandable when reproduced in monochrome.
- [ ] Place figure and table numbers/captions below their content.
- [ ] Avoid excessive appendices and figures; appendices should support rather
      than interrupt the main argument.

## Project records

- [ ] Maintain weekly objectives, completed tasks, achieved targets and meeting
      records in the project log.
- [ ] Record supervisor feedback and the corresponding action.
- [ ] Back up source, report, experimental data and literature records.
- [ ] Retain exact configurations, raw results and negative findings.

## Assessment emphasis

The final report is 70% of the module and must itself achieve a pass. The major
criteria are background research/theory, technical and practical problem
solving, critical appraisal, and written presentation. The proposal is 20% and
the 15-minute presentation/demonstration (including five minutes of questions)
is 10%.
